# AFAQ SYRIA — النسخة المنسقة والمحسّنة

## ما تم تحسينه
- إعادة ضبط المسافات والأحجام والبطاقات والجداول لتكون أوضح على الهاتف والكمبيوتر.
- تحسين القائمة الجانبية على الهاتف وإغلاقها عند الضغط خارجها أو زر Escape.
- إضافة تبديل لغة القوائم الرئيسية بين العربية والإنجليزية والتركية والفارسية. (محتوى الصفحات التفصيلي ما زال يحتاج استكمال الترجمة.)
- إضافة قراءة آمنة لبيانات LocalStorage حتى لا يتوقف تحميل التطبيق إذا وُجد سجل تالف.
- الإبقاء على وظائف الموقع ومحافظه الاستثمارية ونماذج الإدخال كما كانت.
- توحيد مسارات صفحة الدفع مع Cloudflare Worker: `/api/payment/create` و`/api/payment/ipn`، ومزامنة الإدارة عبر `/api/v1/sync`.

## الملفات
- `index.html` — واجهة الموقع.
- `payment.html` — صفحة إنشاء فاتورة NOWPayments.
- `worker.js` — Cloudflare Worker.
- `schema.sql` — مخطط قاعدة بيانات D1.

## نشر الواجهة
1. احتفظ بنسخة احتياطية من المستودع الحالي.
2. ارفع `index.html` و`payment.html` إلى جذر مستودع GitHub Pages.
3. أبقِ ملفات الصور والأيقونات و`manifest.webmanifest` وملفات PWA الحالية في أماكنها.

## إعداد Cloudflare Worker
1. أنشئ D1 واربطه بالاسم `DB`.
2. نفّذ `schema.sql` في قاعدة D1.
3. أضف الأسرار `NOWPAYMENTS_API_KEY` و`NOWPAYMENTS_IPN_SECRET`.
4. اضبط `ALLOWED_ORIGIN` على أصل موقعك الدقيق.
5. انشر `worker.js`، ثم اضبط عنوانه من مركز API داخل الموقع.
6. اجعل مسار IPN عاماً حتى تصل إشعارات NOWPayments، واحمِ مسارات الإدارة `/api/v1/*` عبر Cloudflare Access.
7. عيّن IPN callback في NOWPayments إلى `https://YOUR-WORKER-DOMAIN/api/payment/ipn`.

## تنبيه مهم
- لا تضع مفاتيح API أو أسرار الدفع في `index.html` أو GitHub.
- صفحة الدفع تفتح صفحة الفاتورة المستضافة لدى NOWPayments؛ لا تدّعي هذه النسخة معالجة بطاقات مصرفية داخل الموقع.
- بيانات المشاريع والعملاء المحلية تبقى في متصفح الجهاز إلى أن يتم إعداد المزامنة وقاعدة البيانات واختبار الصلاحيات.
- تبديل اللغة الحالي يغطي القوائم الرئيسية فقط، وليس ترجمة كل نصوص الوحدات بعد.
