# آفاق سوريا — حزمة الموقع والتطبيق

## محتويات الحزمة
- `index.html`: لوحة المنصة، المحافظ والحقائب، معرض الصور، الأسواق العالمية، محفظة الاستثمار التجريبية، الفواتير والتقارير والإعدادات.
- `payment.html`: واجهة إنشاء فاتورة عبر NOWPayments عند إعداد Worker.
- `worker.js` و`schema.sql`: واجهة API وقاعدة بيانات D1 المرفقتان.
- `manifest.webmanifest` و`sw.js` و`icon.svg`: ملفات تثبيت التطبيق كتطبيق ويب تقدمي PWA.

## المزايا المنفذة في هذه النسخة
- هوية موحدة كحلي داكن وذهبي، دون خلفيات بيضاء.
- لغات واجهة القوائم: العربية والإنجليزية والتركية والفارسية.
- لكل حقيبة معرض مستقل مع أزرار ظاهرة دائماً لإضافة الصور وإزالة الصور، وزر للعودة إلى الصفحة الرئيسية أو قائمة الحقائب الاستثمارية. وضع إزالة الصور يعرض زر حذف على الصور المضافة فقط ويحمي الصور الأصلية المدمجة. الصور المضافة تضغط إلى JPEG وتحفظ محلياً في المتصفح/الجهاز.
- عند إعداد API وقاعدة البيانات يمكن مزامنة مجموعات بيانات المحافظ والصور المضغوطة عبر زر المزامنة في مركز API، مع مراعاة حدود حجم السجل في Worker.
- شاشة أسواق عالمية تتضمن مؤشرات TradingView وأسعار أصول رقمية من CoinGecko، مع تحديث دوري. قد تتوقف المصادر أو تحدّ الطلبات؛ عندها تظهر رسالة بدلاً من اختلاق الأسعار.
- محفظة استثمار تجريبية متعددة العملات: إضافة رصيد اختبار، شراء وبيع محاكى، خصم قيمة الشراء من الرصيد، وإضافة قيمة البيع إلى الرصيد، وسجل أوامر وأصول.

## مهم قبل الاستخدام
- المحفظة وأوامر الأسهم في هذه الحزمة محاكاة محلية وليست أموالاً حقيقية أو أوامر تداول فعلية.
- إضافة رصيد في محفظة الاستثمار هي رصيد افتراضي للاختبار فقط.
- لا توجد أسعار صرف تلقائية بين العملات؛ قيمة كل أصل تظهر بعملة تسعيره، ولا تجمع العملات المختلفة في إجمالي موحد.
- لا تنفذ هذه الحزمة تداولاً حقيقياً. يلزم وسيط مرخص وتكامل خادمي ومراجعة قانونية وأمنية قبل تفعيل التنفيذ.
- الصور المضافة تحفظ أولاً على الجهاز الحالي. لمزامنتها بين الأجهزة، اضبط API وD1 ثم استخدم مزامنة البيانات؛ يجب أن يبقى حجم كل مجموعة ضمن حد Worker البالغ 900,000 حرف.
- NOWPayments في `payment.html` لا يعني وجود تحويل مصرفي أو تسوية بنكية.

## النشر على GitHub Pages
1. احتفظ بنسخة احتياطية من ملفات المستودع.
2. ارفع جميع ملفات هذه الحزمة إلى جذر المستودع واستبدل الملفات المناظرة.
3. أبقِ أي ملفات صور أو أصول إضافية تستخدمها المنصة.
4. بعد النشر افتح الموقع عبر HTTPS. استخدم تحديثاً كاملاً للصفحة؛ وسيحدّث Service Worker ذاكرته عند توفر اتصال.
5. لا تضع مفاتيح NOWPayments أو أي أسرار داخل HTML؛ تبقى في Cloudflare Worker Secrets.

## إعداد Cloudflare
- اربط قاعدة D1 باسم `DB` وفق الكود، ونفذ `schema.sql` أو اترك Worker ينشئ الجدولين تلقائياً.
- أضف `NOWPAYMENTS_API_KEY` و`NOWPAYMENTS_IPN_SECRET` كـ Worker Secrets عند الحاجة للدفع.
- اضبط `ALLOWED_ORIGIN` على نطاق الموقع المنشور.
- راجع سياسة Cloudflare Access على مسارات الإدارة `/api/v1/*` قبل اختبار المزامنة؛ أما `/health` وإشعار الدفع فلهما متطلبات وصول مختلفة.
- اختبر `/health` أولاً، ثم المزامنة. لا تشارك رابطاً أو مفتاحاً سرياً في صفحات عامة.
