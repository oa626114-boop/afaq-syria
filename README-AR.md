# AFAQ SYRIA — تحديث الهوية البصرية والمحافظ

## الملفات
- `index.html`: واجهة المنصة بعد توحيد الكحلي والذهبي، قائمة لغة صغيرة، وإضافة وضع إزالة الصور المضافة للمحافظ.
- `payment.html`: صفحة الدفع بألوان متوافقة مع المنصة.
- `worker.js` و`schema.sql`: ملفات الربط الحالية كما هي دون تغيير.

## ما تم تعديله
- جميع الخلفيات الأساسية والبطاقات والقوائم والنوافذ أصبحت كحلية داكنة.
- الكتابة فقط بالذهبي أو الأبيض لسهولة القراءة.
- لا توجد مساحات واجهة بيضاء.
- قائمة اللغة أصبحت قائمة منسدلة صغيرة وتدعم حالياً العربية والإنجليزية والتركية والفارسية في القوائم الرئيسية.
- زر `إزالة الصور` يظهر وضع الحذف، ويمكن إزالة الصور التي أضافها المستخدم إلى كل محفظة على حدة. الصور الأصلية المدمجة محمية من الحذف العرضي.
- إضافة الصور ما زالت تحفظها محلياً على الجهاز/المتصفح الحالي عبر التخزين المحلي.

## النشر
1. احتفظ بنسخة احتياطية من ملفات GitHub الحالية.
2. استبدل `index.html` و`payment.html` بالنسختين الموجودتين هنا.
3. لا تستبدل `worker.js` أو `schema.sql` إذا كان لديك إصدار أحدث منشور؛ الملفان المرفقان هما النسخة المتاحة من الحزمة الحالية.
4. أبقِ `manifest.webmanifest` و`sw.js` و`icon.svg` ومجلدات الصور الحالية في المستودع.
5. بعد النشر، افتح الموقع وحدّثه تحديثاً كاملاً لمسح نسخة الصفحة القديمة من ذاكرة المتصفح.

## ملاحظة
ترجمة القوائم الرئيسية المتاحة حالياً هي العربية والإنجليزية والتركية والفارسية؛ اختيار لغة أخرى يتطلب إضافة ترجمة فعلية لمحتوى الصفحات، ولا يصح إظهار لغة غير مكتملة على أنها مدعومة.
