حزمة تحديث آفاق سوريا
- index.html: القائمة الرئيسية مع روابط القسمين الجديدين.
- global-market.html: رسوم شموع ومتابعة أسواق عبر TradingView. أسعار مزود خارجي؛ ليست قيمة مؤشر AFAQ المركب.
- crypto-wallet.html: واجهة محفظة أولية تربط طلب الدفع بصفحة payment.html. ليست محفظة حاضنة ولا تحفظ أموالاً.
- payment.html وworker.js: نسخ متوافقة مع Worker الذي اختبرناه. لا تستبدل Worker مرة أخرى الآن؛ يعمل حالياً بعد نشره.
طريقة النشر: ارفع ملفات الحزمة إلى جذر مستودع GitHub Pages مع استبدال index.html فقط بالنسخة المرفقة، وأضف بقية الملفات. احتفظ بنسخة احتياطية من index.html الحالي.
قبل تفعيل أرصدة/إيداعات/تحويلات فعلية: يلزم مزود بيانات سوق موثوق، تعريف منهجية مؤشر AFAQ وأوزانه، ومزود محفظة/حفظ مرخص ومراجعة قانونية وامتثال.
