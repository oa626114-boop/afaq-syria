# آفاق سوريا — الحزمة الموحدة

## محتويات الحزمة
- `index.html`: الواجهة الرئيسية، مع بوابة تسجيل/دخول العضوية وربط جلسة العضو بطلبات API.
- `payment.html`: مركز الفواتير، يرسل رمز جلسة العضو إلى Worker.
- `crypto-wallet.html`: واجهة محفظة أولية تحول طلب الدفع إلى مركز الدفع؛ ليست محفظة حفظ أموال.
- `global-market.html`: رسوم TradingView الخارجية؛ الأسعار قد تتأخر ولا تمثل قيمة مؤشر AFAQ المركب.
- `worker.js`: أحدث Worker مرفق، مع العضوية والجلسات والتحويلات وNOWPayments وIPN.
- `schema.sql`: مخطط D1 كامل مطابق لتعريفات Worker بما فيها جدول الاعتمادات وسجل القيود وحدود المحاولات.
- `sw.js`, `manifest.webmanifest`, `icon.svg`, `icon-192.png`, `icon-512.png`: ملفات PWA والتخزين المؤقت وأيقونات التثبيت.

## إعداد Cloudflare Worker الحالي
1. اربط قاعدة D1 باسم binding: `DB`.
2. أضف الأسرار (Secrets): `SESSION_PEPPER` (عشوائي قوي 32 حرفاً على الأقل)، `NOWPAYMENTS_API_KEY`، `NOWPAYMENTS_IPN_SECRET`.
3. أضف المتغيرات (Variables): `ALLOWED_ORIGIN=https://oa626114-boop.github.io` و`ADMIN_EMAIL` ببريد حساب مالك المنصة.
4. تحقق من إعداد CORS إذا كان للموقع نطاق آخر؛ يجب أن يطابق أصل الموقع تماماً.
5. انشر `worker.js` في Worker الحالي `omax-api-105a` بعد أخذ نسخة احتياطية من الكود المنشور.
6. ارفع ملفات الحزمة إلى جذر GitHub Pages بالأسماء كما هي، مع الاحتفاظ بنسخة احتياطية من الملفات القديمة.
7. افتح الموقع، أنشئ حساب العضو، ثم اختبر تسجيل الدخول و`/health` وإنشاء فاتورة اختبارية بمبلغ صغير دون دفع فعلي.

## قواعد مهمة
- لا تضع مفاتيح NOWPayments أو `SESSION_PEPPER` أو رموز الإدارة داخل HTML أو GitHub.
- صفحة الدفع تتطلب تسجيل الدخول في علامة التبويب نفسها لأن رمز العضوية محفوظ في `sessionStorage`.
- مسارات مزامنة بيانات المنصة وقائمة المدفوعات تتطلب جلسة مالك تطابق `ADMIN_EMAIL`.
- الدفع الرقمي عبر NOWPayments هو المسار الوحيد الذي ينشئ فاتورة حالياً. البطاقات وApple Pay وPayPal وPapara والتحويل البنكي ليست تكاملات مفعّلة ولا يجوز عرضها كوسائل دفع متاحة.
- استعادة كلمة المرور عبر البريد غير مفعّلة بعد؛ يلزم مزود بريد ومسارات رموز مؤقتة ومحدودة المحاولات قبل إتاحتها.
- واجهة محفظة العملات الرقمية ليست محفظة حاضنة ولا تنشئ عناوين بلوكشين أو مفاتيح خاصة.
- التحويلات الداخلية تعتمد أرصدة D1. لا تمثل أموالاً مصرفية أو أرصدة نقدية مضمونة؛ لا تستخدمها لأموال حقيقية قبل شريك مالي مرخص ومراجعة الامتثال.
- أرقام الحساب الداخلية ليست IBAN مصرفياً.
- مؤشر AFAQ المركب لا يعرض سعراً رسمياً؛ يلزم مزود بيانات مرخص ومنهجية وأوزان منشورة.

## ما تم فحصه محلياً
تم فحص صياغة JavaScript للـ Worker وسكربتات الصفحات، وصحة JSON للـ manifest، وإمكانية تنفيذ schema.sql على SQLite. أضيفت مطابقة مبلغ/عملة/معرّف الفاتورة قبل قيد الدفعة، وتقييد عملة الدفع إلى العملات الرقمية المسموحة، وتصحيح خطأ تهيئة نموذج الدفع، وفرض خلفيات كحلية وذهبية، وإضافة أيقونات PWA بقياسي 192 و512 بكسل. لم يتم الاتصال بحساب Cloudflare أو GitHub أو NOWPayments من هذه البيئة، لذلك لا يمكن تأكيد النشر أو أسرار البيئة أو الدفع الحي.
