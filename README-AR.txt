AFAQ WALLET — حزمة إصلاح الواجهة
================================

ما تم إصلاحه:
1) إضافة index.html مستقل للمحفظة بدلاً من الاعتماد على ملفات غير موجودة.
2) ربط styles.css فعلياً عبر <link rel="stylesheet">.
3) وضع وظائف الواجهة في app.js خارجي محمّل عبر defer حتى لا يظهر الكود كنص داخل الصفحة.
4) إضافة manifest.webmanifest و icon.svg الناقصين.
5) تحديث Service Worker إلى cache v3 مع تضمين الأصول الجديدة.
6) ربط تسجيل الدخول/التسجيل بواجهات العضوية الموجودة في Worker نفسه، بحيث يستخدم العضو حساب AFAQ SYRIA نفسه وقاعدة البيانات المشتركة.
7) ربط ملخص المحفظة والتعدين وسجل المكافآت والتحويلات الداخلية بالـ API، وعدم إنشاء أرصدة وهمية عند فشل الاتصال.
8) تقوية تسلسل إغلاق جلسة التعدين: تُضاف المكافأة وقيود دفتر الأستاذ ويُحدّث الرصيد فقط إذا نجح إغلاق الجلسة في العملية الحالية، لمنع التكرار عند الطلبات المتزامنة.

قبل النشر:
- انشر محتويات هذا المجلد كاملة في جذر استضافة AFAQ WALLET.
- تأكد أن Worker منشور وأن D1 binding باسم DB موجود.
- اضبط SESSION_PEPPER بقيمة عشوائية طويلة (32 حرفاً على الأقل).
- اضبط ALLOWED_ORIGIN على أصل الموقع الذي سيستضيف المحفظة، دون مسار الصفحة.
- اضبط AFAQ_MINING_RATE_PER_HOUR من إعدادات Worker بقيمة وافق عليها مشرف المنصة. إذا كانت 0 أو غير موجودة فسيبقى التعدين معطلاً.
- افتح المحفظة واضغط ⚙ ثم أدخل رابط Worker المنشور واضغط حفظ واختبار الاتصال.
- سجّل الدخول بحساب العضوية الموجود على الخادم. لا تستخدم بيانات حساب تجريبي محلي.

ملاحظات مهمة:
- الحزمة لا تنشئ قيمة نقدية أو رمز بلوكشين. AFAQ هنا نقاط مكافآت داخلية فقط.
- التحويلات تستخدم عملات الحسابات الموجودة في Worker (USD/EUR/TRY/SYP/GBP/AED/SAR)، ولا يوجد تحويل نقاط AFAQ إلى أموال.
- لا تُرفع مفاتيح API أو أسرار Worker إلى ملفات الواجهة.
- لا تمسح بيانات المتصفح أو قاعدة البيانات أثناء الاختبار.
- تم اختبار الصياغة وفحص الملفات محلياً فقط. لم يتم النشر إلى Cloudflare أو GitHub ولم يتم اختبار اتصال حي بقاعدة بيانات الإنتاج.
