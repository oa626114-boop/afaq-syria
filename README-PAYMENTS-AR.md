# AFAQ SYRIA — تحديث مركز الدفع والفواتير

## الملفات
- `index.html` — نسخة المنصة الاحترافية مع نموذج فاتورة ورابط دفع للعملات الرقمية.
- `payment.html` — مركز دفع مستقل متوافق مع الهوية الكحلية والذهبية.
- `worker.js` — Cloudflare Worker متوافق مع `/api/payment/create` و`/api/payment/ipn` و`/api/payment/status`.

## ما يعمل في هذه النسخة
- إنشاء فاتورة مستضافة عبر NOWPayments للعملات: USDT TRC20 وUSDT ERC20 وBTC وETH وTRX، مع خيار كل العملات المتاحة أو fiat On-Ramp (إذا فُعّل في حساب التاجر).
- حفظ مرجع الطلب ورابط الفاتورة في سجل الفواتير المحلي في المتصفح.
- فتح رابط الدفع ونسخه لمشاركته مع العميل.
- استقبال IPN والتحقق من توقيع HMAC-SHA512 وتحديث حالة الدفع في D1.
- إظهار وسائل البطاقات وApple Pay وPayPal وPapara بوضوح على أنها تحتاج حساب تاجر/اعتماد ومفاتيح مزود؛ لا يتم إنشاء روابط وهمية لها.

## النشر الآمن
1. احتفظ بنسخة احتياطية من الملفات الحالية.
2. استبدل `index.html` بالملف المسمى `AFAQ-SYRIA-PROFESSIONAL-index.html` بعد إعادة تسميته إلى `index.html` فقط.
3. ارفع `payment.html` إلى جذر المستودع.
4. انشر `worker.js` في Cloudflare Worker المستخدم حالياً.
5. أبقِ أسرار `NOWPAYMENTS_API_KEY` و`NOWPAYMENTS_IPN_SECRET` في Worker Secrets فقط.
6. تأكد من وجود D1 binding باسم `DB`، واضبط `ALLOWED_ORIGIN` على أصل GitHub Pages الصحيح، مثل `https://oa626114-boop.github.io`.
7. اضبط NOWPayments IPN callback إلى `https://omax-api-105a.oa626114.workers.dev/api/payment/ipn`.
8. اختبر `/health` ثم أنشئ فاتورة صغيرة من مركز الدفع. لا تعتبرها مدفوعة إلا بعد وصول IPN صحيح وتحديث الحالة.

## بوابة البطاقات والمحافظ
الواجهة تعرض Visa/Mastercard وApple Pay كمسار محتمل عبر NOWPayments Fiat On-Ramp، لكن يجب تفعيل Fiat Operations/Coins Settings وإكمال KYC/KYB. قد يحوّل مزود الطرف الثالث مدفوعات الفيات إلى عملة رقمية تُرسل إلى محفظتك؛ هذا ليس بالضرورة تسوية بطاقات مباشرة إلى البنك، وتختلف الوسائل حسب البلد والمزود. PayPal وPapara يحتاجان مساراً مستقلاً وحساباً مؤهلاً. PayTR يذكر في صفحة الدعم الرسمية أنه يقبل حالياً الشركات المسجلة في تركيا أو شمال قبرص فقط؛ لذلك لا تفترض قبول OMAXSOLUTIONS LLC المسجلة خارج تركيا. يمكن سؤال iyzico عن أهلية كيان الشركة وطريقة Link قبل كتابة أي مفاتيح.

## ملاحظات مهمة
- لا تضع API keys أو بيانات البطاقات في `index.html` أو `payment.html` أو GitHub.
- صفحة الدفع لدى NOWPayments مستضافة خارج الموقع؛ الرابط قابل للمشاركة، لكن الدفع لا يتم داخل حقول موقعنا.
- سجل الفواتير في `index.html` ما زال يحفظ محلياً على الجهاز. قاعدة D1 تحفظ سجلات الدفع/مراجع الطلبات فقط في هذا الإصدار.
- اختبر في بيئة ومبالغ منخفضة قبل قبول دفعات العملاء الحقيقية.
