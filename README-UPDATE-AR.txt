تحديث حساب المشترك لمنصة آفاق سوريا
1) استبدل ملف index.html في مستودع GitHub بهذا الملف.
2) لا تستبدل worker.js أو schema.sql أو payment.html.
3) يتضمن واجهة بطاقة افتراضية أولاً، وبطاقات تعريف المشترك والحساب البنكي والمحفظة الرقمية.
4) البطاقة الافتراضية الحالية معاينة واجهة فقط؛ تفعيلها للشراء أو الدفع يحتاج مزود إصدار بطاقات مرخصاً وربطاً خادمياً. لا تستخدم أرقاماً تجريبية كأنها بطاقة حقيقية.
5) يمكن إضافة بطاقة بلاستيكية فعلية في مرحلة لاحقة.
