# AFAQ WALLET — النسخة الأولية

هذه حزمة واجهة أولية متجاوبة (PWA) يمكن فتحها على الهاتف، ويمكن تثبيتها كتطبيق ويب عند استضافتها عبر HTTPS.

## الموجود حالياً
- واجهة عربية RTL بألوان كحلية وذهبية.
- لوحة رصيد AFAQ COIN بحالة غير مفعّلة.
- واجهة منجم آفاق ورسوم نحلة متحركة.
- أزرار أولية للخدمات.
- ملف manifest وخدمة تخزين مؤقت PWA.

## غير الموجود بعد
- لا يوجد تسجيل دخول حقيقي أو ربط بعضوية AFAQ SYRIA.
- لا توجد قاعدة بيانات أو خادم API.
- لا تُحتسب مكافآت ولا تُنشأ أرصدة فعلية.
- لا توجد تحويلات مالية حقيقية أو عناوين إيداع.

## الخطوة التالية قبل أي إطلاق
إنشاء خادم موثوق وقاعدة بيانات وسجل قيود مالي (ledger)، ثم تنفيذ:
1. مصادقة الأعضاء عبر خادم AFAQ SYRIA أو تكامل موثق وآمن.
2. جلسات دخول آمنة ومصادقة متعددة العوامل عند الحاجة.
3. جداول الأعضاء والمحافظ والقيود وسجل التعدين.
4. احتساب المكافآت على الخادم فقط مع حدود يومية ومنع التكرار.
5. اختبارات أمنية واختبارات تزامن ومراجعة صلاحيات.
6. سياسة واضحة للمكافآت وشروط الاستخدام قبل إتاحتها للأعضاء.

لا تضع مفاتيح API أو أسراراً داخل ملفات الواجهة أو مستودع GitHub العام.
