# AFAQ BANK — Card artwork assets

This folder is reserved for approved AFAQ BANK card artwork. It is an asset-preparation area only.

## Publication status
- All card artwork in this folder is **draft / hidden**.
- Nothing in this folder is linked from the member-facing AFAQ SYRIA interface.
- Do not display or advertise any card as issued, active, or available until the issuer/acquirer agreement, licensing, compliance review, and production approval are complete.

## Required artwork slots

| Asset key | Intended artwork | Filename | Status |
|---|---|---|---|
| virtual | AFAQ BANK virtual card | `virtual-card.webp` | Awaiting approved artwork |
| visa_physical | AFAQ BANK physical card — Visa program | `visa-physical-card.webp` | Awaiting approved artwork and program approval |
| mastercard_physical | AFAQ BANK physical card — Mastercard program | `mastercard-physical-card.webp` | Awaiting approved artwork and program approval |

## Image requirements
- Preferred format: WebP or PNG; transparent PNG only when needed.
- Keep a clean front-side artwork image; provide a separate back-side image only if specifically required.
- Never place real cardholder data, full PAN, CVV/CVC, PIN, live expiry date, QR payment credentials, or real account details in artwork.
- Use clearly fictional sample data in design previews, or omit card numbers entirely.
- Use Visa and Mastercard marks only after confirming the applicable brand and issuer/acquirer design rules.
- Keep source design files separately from optimized website images.

## Integration rule
These files are not to be imported into the member UI until an explicit release step is approved. The member-facing bank section remains unchanged and continues to show no card images.
